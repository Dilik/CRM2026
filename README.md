# Goodwell Service OS

All-in-one business management platform for **Goodwell.uz** after-sales service center.

## Stack
- **Next.js 16** + TypeScript + App Router
- **Tailwind CSS 4** + shadcn/ui
- **PostgreSQL** + Prisma ORM
- **tRPC** — type-safe API
- **next-intl** — uz/ru/en multilingual

## Modules (planned)
1. CRM — customers & contacts
2. Service Orders — repair job tracking
3. Warehouse — spare parts inventory
4. Finance — invoices & payments
5. Staff & HR — employees & roles
6. Reports & Analytics

## Getting Started

```bash
cd goodwell-service-os
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)
